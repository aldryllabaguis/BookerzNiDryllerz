# BookerzNiDryllerz

A personal Computer Programming 1 e-portfolio built as a responsive, interactive flipbook.

## Deploy with GitHub Pages

1. Open the repository **Settings**.
2. Select **Pages** in the sidebar.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and `/ (root)` folder, then save.
5. After GitHub finishes publishing, the site will be available at `https://aldryllabaguis.github.io/BookerzNiDryllerz/`.

The homepage is `index.html`. Replace the sample text, links, and `photo.png` with your own content and image when ready.
